项目 01

论文辅导流水线

2024 至今 · 自己独立开发并运营
项目机制
闲鱼 AI 获客系统 + 小红书获客系统 + 自建接单管理后台三者搭配，完成从获客到客户管理，作为论文辅导流水线的前端。论文辅导流水线按学生交付周期推进，全周期对应开发出一整套服务 agent。
辅导专业类目
MBA、MPA、MEM、金融、经济学、法律、教育学等专业，主攻硕士学位论文辅导，兼顾本科和期刊辅导，额外辅导比赛类论文。
落地场景 agent
文献综述 agent、论文框架 agent、论文润色 agent、实证分析 agent。
选题开题中期初稿预答辩盲审答辩
文献综述 agent

自己写爬虫，把「找文献」固化成一套动作：定关键词、多库检索（知网 / 万方 / 维普 / Google Scholar / 百度学术）、抓取、去重、导出，每单只换参数。再用 DeepSeek 做选题方向分析

论文框架 agent

Claude Code 给每个项目配一套工作流，自动生成文献综述和技术路线。文献综述整合是提示词驱动的固定流程：分板块 → 内容衔接 → 逐块写摘要 → 整合成稿。参考文献格式自动逐条核对

实证分析 agent

工商管理、实证分析、法律等方向都覆盖，按前两段产出的框架和素材生成正文

交付效果
交付周期从 20 天稳定压到 4–5 天

项目 02

小红书需求生产流水线

2026.08 至今
从千帆 8 个榜单入口找真实需求 → 人工判断需求可执行性 → 形成可执行、可复用的日更内容。

把「找需求 → 做产品 → 生成内容」整条链路拆成三段物理隔离的子系统，每段职责清晰、不跨界写数据：

找需求 · 8 个 Agent

千帆平台商家后台榜单采集 → 账号打分筛选 → 安卓真机 + ADB 控制 + OCR 抓店铺商品分享短链 → Playwright 商品归档 → 产出「带证据的需求卡」

机会转产品 · B1–B4

需求筛选求实、原创产品设计、事实核验、与生成侧交接同步，人工判断哪些需求真能落地

内容生成 · 9 环节

产品资料整理 → 关键词 → 对标采集 → 拆解 → 模板 → 待审内容包，产出可直接排期的日更内容

技术：bash 脚本 + SQLite + 安卓自动化（ADB / RapidOCR）+ Playwright 持久化登录 + Obsidian。

系统内 agent 的拼装与拆解：把单个环节拆分开，对应的 agent 可移植、可拼装复用。
